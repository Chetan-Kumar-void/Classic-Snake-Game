Program Statement: Snake Game (C Language)

➤ Objective:
To create a simple console-based Snake Game using C that demonstrates real-time input handling and basic game logic.

➤ Game Overview:

The game runs on a 40 × 20 grid.
The player controls a snake using keys:
8 ↑ (Up)
2 ↓ (Down)
4 ← (Left)
6 → (Right)
The snake moves continuously on the screen.

➤ Game Mechanics:

@ → Snake head
+ → Snake body
F → Food
# → Boundary walls
The snake grows when it eats food.
Food is placed randomly on the board.
The game ends if the snake:
Hits the wall
Collides with itself

➤ Key Features:

Real-time movement using a game loop
Non-blocking keyboard input (smooth control)
Random food generation
Collision detection
Dynamic board rendering in terminal

➤ Concepts Used:

Arrays and Structures
Functions and Loops
Conditional Statements
File handling of terminal input (termios, fcntl)

➤ Output:
A playable Snake Game in the terminal that ends with a "Game Over" message upon collision.
